# Case files

One folder per client, dummy or real. Same structure for every client, so it becomes the firm's standard client folder.

```
<client-name>/
  README.md            client snapshot: business, owner, period, status
  01-kyc-onboarding/
  02-books/YYYY-MM/
  03-bank/YYYY-MM/
  04-compliance/       GST, TDS, income tax, ROC
  05-reports/          month-end checklist, P&L, BS, MIS, health report
  06-notes-queries/
```

| Client | Type | Used in | Status |
|---|---|---|---|
| [Annapurna Stationers](annapurna-stationers/) | Dummy: small trading shop | Week 01 | Active |

No real client ID numbers (PAN, Aadhaar, bank account numbers) in this repo, ever. Real client data stays in the firm's own storage.
