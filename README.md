# CA practice learning

Everything for his 12-month learning plan, in one place. The plan itself: [learning roadmap](roadmap/README.md).

## Layout

```
ca-learning/
  README.md            this file: how the system works
  roadmap/             the 12-month learning roadmap (summary + PDF)
  tracker.md           one-page progress view: all 70 modules, phase, status
  weeks/               one folder per week, named by the Monday's date
    2026-11-02-week-01/
      assignment.pdf   what pradeep sends to the WhatsApp group
      submission/      his workbook and end-of-week note
      review.md        Saturday review notes, scores, next week
  modules/             notes per module group (A-I), with status tables
  case-files/          dummy and pilot clients he works on
    annapurna-stationers/
  assessments/         the diagnosis exam, the Phase 0 graduation test, phase reviews
  templates/           weekly assignment, weekly review, module notes, daily update
```

## Weekly loop

1. **Sunday/Monday:** pradeep writes the week's assignment in `weeks/<date>-week-NN/`, from [the template](templates/weekly-assignment.md). It is shared in the WhatsApp group as a PDF.
2. **Mon-Fri:** he sends a one-line update each evening ([format](templates/daily-update.md)). Work goes in the week's `submission/` and the client folder in `case-files/`.
3. **Friday 7 pm:** he submits the workbook and a 5-line note.
4. **Saturday 10:00 sync:** review using [the review template](templates/weekly-review.md); scores go into `review.md`, and module status in [tracker.md](tracker.md) and `modules/` gets updated.

## Status values

Not started → In progress → Practised (done on a case) → Assessed (passed a review or test). Score /5 = how well he can explain and apply it, set at the Saturday review.

## Mirror on Drive (optional)

If he works in Google Drive, mirror `weeks/`, `case-files/` and `assessments/` there as folders with the same names; keep the tracker here.
